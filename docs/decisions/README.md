## M6-0 최소 자동 진행·관찰 계약

사용자는 B의 v0.1 범위·책임 검토 PASS, v0.2 보완안 PASS와 마지막 접촉 문장 정정을 확인한 뒤 M6-0 v0.2를 설계 정본으로 승인했다. [M6-0 v0.2 정본](m6-0-v0.2.md)은 이 승인 내용을 통합한 문서이며, 채팅 원문을 바이트 단위로 복제한 파일은 아니다.

- 상태: `CANONICAL / USER APPROVED`.
- 정본 파일 SHA-256: `a8bcb4fb2346a3eb185ca50c0df0cf988d623d7dd2c7f6ff515998bf652332f8`.
- B 검토: `PASS / BLOCKER NONE`; 기존 두 보완 사항은 설계 계약상 `CLOSED`.
- 최종 표현: 자동 판단 대상이 없으면 행동만 생략한다. 유효한 접촉쌍은 처리하고, 접촉쌍도 없을 때에만 빈 접촉 계획을 처리한다.
- 기준선: M5 `main@6d4aa8ad607b42c1ee6472c1b72b9d85b90ce369`, tree `9ef2415eb25eef9a5b6d5b0b7d17fbd3fe1dd6e1`.
- M6-0은 기존 M6의 60명·행동군 확장에 앞선 단계이며 기존 M6 전체 완료를 뜻하지 않는다.
- 구현 승인은 `NOT GRANTED`다. 설계 정본 채택은 구현·시험 PASS·PR 병합 승인을 뜻하지 않는다.
- 프로젝트 동기·역사 세계관·초기 인물 조사·캐릭터 모델 첨부 자료는 방향성 참고로 유지한다.
